# Sürüm Notları

Her sürüm için `vX.Y.Z.md` dosyası (ör. `v1.0.1.md`). `npm run release -- patch`
şablonu otomatik oluşturur; yayınlamadan önce doldurun. Dosya hem GitHub Release
gövdesi hem de masaüstü uygulamasındaki güncelleme penceresinde gösterilir.

Başlıklar:

- **YENİ** — eklenen özellikler
- **DÜZELTME** — giderilen hatalar
- **PERFORMANS** — iyileştirmeler

Boş bölümü olan dosya yayınlamayın; kullanıcının görmesi istenmeyen başlığı silin.
